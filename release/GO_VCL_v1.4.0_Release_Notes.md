# GO_VCL v1.4.0 发行说明

## 发布日期
2025年11月14日

## 主要更新内容

### 1. TCP服务器乱码修复
- 修复了TCP服务器接收和发送消息时的乱码问题
- 优化了UTF-8编码处理机制
- 改进了字符编码转换流程

### 2. 新增功能
- 添加了UTF-8编码自动检测功能
- 增强了TCP服务器的稳定性
- 改进了错误处理机制

### 3. 界面优化
- 优化了TCP服务器界面布局
- 改进了用户体验

## 安装说明
1. 解压压缩包到任意目录
2. 双击运行"启动GO_VCL.bat"启动应用程序
3. 或者直接运行"windows-gui-app.exe"

## 系统要求
- Windows 7/8/10/11
- 至少50MB可用磁盘空间
