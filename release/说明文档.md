# GO_VCL Windows窗口程序项目

## 项目规划

### 项目概述
创建一个基于Go语言的Windows窗口应用程序，使用Govcl UI库，提供完整的GUI界面和多功能集成。项目已实现图片展示功能，支持在README.md中添加应用程序界面截图和应用图标。

### 技术栈
- **主框架**: github.com/ying32/govcl
- **Excel操作**: github.com/xuri/excelize/v2  
- **JSON处理**: github.com/tidwall/gjson
- **HTTP请求**: github.com/kirinlabs/HttpRequest
- **数据库**: SQLite3（当前为模拟模式）

### 核心功能模块
1. **UI组件模块**: 标签、按钮、表格、编辑框、状态栏
2. **数据操作模块**: Excel导入导出、JSON解析生成
3. **网络通信模块**: HTTP GET/POST请求，支持JSON API
4. **数据存储模块**: SQLite3数据库操作（模拟模式）
5. **错误处理**: 完善的异常处理和状态管理
6. **Excel导入**: 新增Excel文件导入功能，用户可选择文件导入到表格显示
7. **并发处理**: 多线程任务管理，支持并发执行和结果收集
8. **图片展示**: 在README.md中添加应用程序界面截图和应用图标，提升项目展示效果
