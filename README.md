# GO VCL 多功能演示程序

这是一个基于Go VCL框架开发的多功能桌面应用程序，集成了Excel、JSON、HTTP和SQLite数据库操作功能。

## 功能特性

### 📊 Excel操作
- Excel文件导入/导出
- 数据表格操作
- 批量数据处理

### 🔧 JSON操作
- JSON数据解析和验证
- JSON文件读写
- 数据转换和处理

### 🌐 HTTP网络操作
- HTTP GET/POST/PUT/DELETE请求
- 文件下载功能
- 请求头和参数管理

### 💾 数据库操作
- SQLite数据库管理
- CRUD操作（创建、读取、更新、删除）
- 演示数据生成

## 项目结构

```
windows-gui-app/
├── main.go                  # 主程序入口
├── go.mod                   # Go模块定义
├── ui/
│   └── MainForm.go          # 主窗口UI定义
├── handlers/
│   └── button_handlers.go   # 按钮事件处理器
├── managers/
│   ├── excel_manager.go     # Excel操作管理器
│   ├── json_manager.go      # JSON操作管理器
│   ├── http_manager.go      # HTTP操作管理器
│   └── database_manager.go  # 数据库操作管理器
├── utils/
│   └── helpers.go           # 工具函数库
└── data/                    # 数据目录（运行时创建）
    ├── demo.db             # 演示数据库文件
    ├── demo.json           # 演示JSON文件
    └── demo.xlsx           # 演示Excel文件
```

## 编译和运行

### 环境要求
- Go 1.20+
- Windows操作系统
- VCL框架运行时库

### 编译步骤

1. 安装依赖：
   ```bash
   go mod tidy
   ```

2. 编译程序：
   ```bash
   go build -o windows-gui-app.exe main.go
   ```

3. 运行程序：
   ```bash
   ./windows-gui-app.exe
   ```

## 使用说明

### 启动程序
运行程序后，会显示主窗口界面，包含以下功能模块的入口按钮：
- Excel操作
- JSON操作  
- HTTP操作
- 数据库操作

### 快速开始
1. 点击"创建演示数据"按钮生成示例数据
2. 使用各个功能模块进行数据操作
3. 查看操作结果和状态信息

### 功能操作

#### Excel操作
1. 点击"Excel操作"按钮
2. 导入Excel文件或导出当前数据
3. 在表格中查看处理结果

#### JSON操作  
1. 在输入框中输入JSON数据
2. 点击JSON按钮进行解析和验证
3. 保存或加载JSON文件

#### HTTP操作
1. 输入目标URL
2. 选择HTTP方法
3. 发送请求并查看响应

#### 数据库操作
1. 创建或连接SQLite数据库
2. 执行SQL操作（插入、查询、更新、删除）
3. 在表格中查看查询结果

## 故障排除

### 常见问题

1. **程序无法启动**
   - 检查是否安装了VCL运行时库
   - 确认Go环境配置正确

2. **依赖库问题**
   - 运行 `go mod tidy` 更新依赖
   - 检查网络连接和代理设置

3. **数据库操作失败**
   - 确认SQLite驱动已正确安装
   - 检查数据目录权限

### 调试模式
程序内置了详细的日志输出，可以在控制台中查看操作过程和错误信息。
