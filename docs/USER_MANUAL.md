# GO_VCL Windows GUI程序 - 用户使用手册

## 🎯 欢迎使用

本手册将指导您如何使用GO_VCL Windows GUI程序，这是一个功能强大的桌面应用程序，支持Excel文件处理、JSON数据操作、HTTP网络请求和数据库管理功能。

## 📋 程序启动

### 启动方式
1. **双击可执行文件**: 找到程序安装目录，双击`GO_VCL.exe`
2. **开始菜单**: 通过Windows开始菜单找到程序图标

## 📊 Excel文件操作

### 功能概述
Excel模块支持.xlsx格式的文件导入导出，可以将Excel数据显示在程序表格中，也可以将表格数据导出为Excel文件。

### 导入Excel文件

#### 操作步骤
1. **点击"Excel操作"按钮** → 选择"导入Excel"选项
2. **选择Excel文件**:
   - 点击"浏览"按钮打开文件选择对话框
   - 导航到您的Excel文件所在位置
   - 选择`.xlsx`格式的文件
   - 点击"打开"确认选择

3. **设置导入选项** (可选):
   - 工作表选择: 如果文件有多个工作表，可选择特定工作表
   - 起始行: 设置从第几行开始导入数据
   - 列范围: 可选择导入特定列范围

4. **开始导入**:
   - 点击"导入"按钮
   - 观察状态栏显示导入进度
   - 导入完成后，数据将显示在表格区域

#### 支持的Excel格式
- **文件格式**: `.xlsx` (Excel 2007及以上版本)
- **最大行数**: 1,048,576行 (Excel限制)
- **最大列数**: 16,384列 (Excel限制)
- **数据类型**: 文本、数字、日期、布尔值

#### 导入示例
假设您有一个名为`员工信息.xlsx`的文件：
```
工作表: Sheet1
┌──────┬──────┬──────┬──────────┐
│ 姓名 │ 年龄 │ 部门 │ 入职日期 │
├──────┼──────┼──────┼──────────┤
│ 张三 │ 28   │ 技术 │ 2023-01-15│
│ 李四 │ 32   │ 销售 │ 2022-08-20│
│ 王五 │ 25   │ 人事 │ 2023-03-10│
└──────┴──────┴──────┴──────────┘
```

导入后，程序表格将显示相同的数据结构。

### 导出Excel文件

#### 操作步骤
1. **准备数据**:
   - 确保表格中有需要导出的数据
   - 可以通过导入或手动输入添加数据

2. **点击"Excel操作"按钮** → 选择"导出Excel"选项

3. **设置导出选项**:
   - 点击"浏览"按钮选择保存位置
   - 输入文件名（程序自动添加.xlsx扩展名）
   - 选择要导出的数据范围（全部或选定行）

4. **开始导出**:
   - 点击"导出"按钮
   - 状态栏显示导出进度
   - 完成后显示成功消息

#### 导出设置
- **文件命名**: 支持中文、英文、数字
- **保存位置**: 任意有写入权限的文件夹
- **数据格式**: 保持原有格式和结构

### Excel操作常见问题

#### 问题1: 导入失败，提示"文件格式不支持"
**原因**: 文件可能是旧版Excel格式(.xls)或其他格式
**解决**: 
1. 在Excel中打开文件
2. 点击"文件" → "另存为"
3. 选择"Excel工作簿(*.xlsx)"格式
4. 重新导入新保存的文件

#### 问题2: 中文显示乱码
**原因**: 文件编码问题或字体不支持
**解决**:
1. 检查系统区域设置
2. 确保使用支持中文的字体
3. 在Excel中重新保存文件

#### 问题3: 大数据量导入慢
**原因**: 文件过大或系统资源不足
**解决**:
1. 分批导入数据
2. 关闭其他占用内存的程序
3. 增加系统虚拟内存

## 📝 JSON数据操作

### 功能概述
JSON模块支持解析JSON格式数据、修改JSON内容、生成JSON文件，以及JSON与表格数据的相互转换。

### 解析JSON数据

#### 操作步骤
1. **点击"JSON操作"按钮** → 选择"解析JSON"选项
2. **输入JSON数据**:
   - 在文本框中粘贴JSON字符串
   - 或点击"加载文件"选择.json文件
   - 或点击"示例"加载预设的JSON数据

3. **设置解析选项** (可选):
   - 显示模式: 树形结构或表格形式
   - 键值对显示: 显示完整路径或仅显示键名

4. **开始解析**:
   - 点击"解析"按钮
   - 数据将以表格形式显示
   - 左侧显示键路径，右侧显示对应值

#### JSON格式要求
```json
{
    "name": "产品列表",
    "version": "1.0",
    "products": [
        {
            "id": 1,
            "name": "笔记本电脑",
            "price": 5999.99,
            "specs": {
                "cpu": "Intel i7",
                "ram": "16GB",
                "storage": "512GB SSD"
            }
        },
        {
            "id": 2,
            "name": "无线鼠标",
            "price": 199.99,
            "specs": {
                "type": "蓝牙",
                "battery": "充电式"
            }
        }
    ],
    "metadata": {
        "total": 2,
        "lastUpdate": "2023-11-12"
    }
}
```

#### 解析结果显示
```
键路径                    │ 值
─────────────────────────┼──────────────────
name                     │ 产品列表
version                  │ 1.0
products.0.id            │ 1
products.0.name          │ 笔记本电脑
products.0.price         │ 5999.99
products.0.specs.cpu     │ Intel i7
products.0.specs.ram     │ 16GB
products.1.id            │ 2
products.1.name          │ 无线鼠标
metadata.total           │ 2
metadata.lastUpdate      │ 2023-11-12
```

### 修改JSON数据

#### 操作步骤
1. **加载JSON数据**: 先解析JSON数据到表格
2. **编辑数据**:
   - 直接在表格中修改值
   - 使用"添加键值对"按钮添加新数据
   - 使用"删除"按钮移除数据项

3. **保存修改**:
   - 点击"生成JSON"按钮
   - 修改后的JSON将在文本框中显示
   - 可保存到文件或复制使用

#### 高级编辑功能
- **路径导航**: 支持点号路径访问，如`products.0.specs.cpu`
- **数据类型保持**: 自动识别字符串、数字、布尔值
- **数组操作**: 支持添加、删除数组元素
- **嵌套结构**: 支持多层嵌套的JSON结构

### 保存JSON文件

#### 操作步骤
1. **准备JSON数据**: 确保有解析或生成的JSON内容
2. **点击"保存文件"按钮**
3. **选择保存位置**:
   - 选择文件夹
   - 输入文件名（自动添加.json扩展名）
4. **确认保存**: 点击"保存"完成操作

### JSON操作示例场景

#### 场景1: API响应数据查看
```json
// 从API获取的响应数据
{
    "status": "success",
    "data": {
        "users": [
            {"id": 1, "name": "张三"},
            {"id": 2, "name": "李四"}
        ],
        "pagination": {
            "page": 1,
            "total": 100
        }
    }
}
```

#### 场景2: 配置文件编辑
```json
{
    "app": {
        "name": "MyApp",
        "version": "2.0",
        "settings": {
            "theme": "dark",
            "language": "zh-CN"
        }
    }
}
```

### JSON操作常见问题

#### 问题1: 解析失败，提示"格式错误"
**原因**: JSON格式不正确
**解决**:
1. 检查引号是否配对
2. 确保使用英文引号
3. 检查逗号位置
4. 使用在线JSON验证工具

#### 问题2: 中文显示为乱码
**原因**: 编码问题
**解决**:
1. 确保文件使用UTF-8编码
2. 检查系统区域设置
3. 重新保存JSON文件

## 🌐 HTTP网络请求

### 功能概述
HTTP模块支持发送GET、POST等HTTP请求，自动处理JSON响应，支持文件下载功能。

### 发送GET请求

#### 操作步骤
1. **点击"HTTP操作"按钮** → 选择"发送请求"选项
2. **输入URL地址**:
   - 在地址栏中输入完整的URL
   - 例如: `https://api.github.com/users/octocat`
   - 或使用示例URL列表中的地址

3. **选择请求方法**: 选择"GET"

4. **设置请求头** (可选):
   - 点击"添加请求头"
   - 输入头名称和值
   - 例如: `Accept: application/json`

5. **发送请求**:
   - 点击"发送"按钮
   - 等待响应返回
   - 查看响应状态、头信息和内容

#### GET请求示例

**API测试接口**:
```
URL: https://jsonplaceholder.typicode.com/posts/1
方法: GET
响应:
{
    "userId": 1,
    "id": 1,
    "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
    "body": "quia et suscipit..."
}
```

**GitHub API**:
```
URL: https://api.github.com/users/octocat
方法: GET
响应: 用户详细信息JSON
```

### 发送POST请求

#### 操作步骤
1. **输入URL地址**: 例如API的提交端点
2. **选择请求方法**: 选择"POST"
3. **设置请求体**:
   - 选择内容类型: JSON、表单或纯文本
   - 在文本框中输入请求数据

4. **设置请求头**:
   - 通常需要设置`Content-Type`
   - 例如: `Content-Type: application/json`

5. **发送请求**: 点击"发送"按钮

#### POST请求示例

**JSON数据提交**:
```http
POST https://jsonplaceholder.typicode.com/posts
Content-Type: application/json

{
    "title": "测试标题",
    "body": "这是测试内容",
    "userId": 1
}
```

**表单数据提交**:
```http
POST https://httpbin.org/post
Content-Type: application/x-www-form-urlencoded

name=张三&age=25&city=北京
```

### 文件下载

#### 操作步骤
1. **点击"HTTP操作"按钮** → 选择"文件下载"选项
2. **输入文件URL**: 例如图片、文档等下载链接
3. **选择保存位置**:
   - 点击"浏览"选择文件夹
   - 输入保存的文件名
4. **开始下载**:
   - 点击"下载"按钮
   - 查看下载进度
   - 完成后显示保存路径

#### 下载示例
- **图片下载**: `https://example.com/image.jpg`
- **文档下载**: `https://example.com/document.pdf`
- **软件下载**: `https://example.com/software.zip`

### HTTP操作高级功能

#### 响应处理
程序会自动识别响应内容类型：
- **JSON响应**: 自动格式化显示，支持展开/折叠
- **HTML响应**: 显示页面标题和主要标签
- **纯文本**: 直接显示内容
- **二进制文件**: 显示文件大小和类型

#### 状态码说明
```
200 - 请求成功
201 - 创建成功
400 - 请求错误
401 - 未授权
403 - 禁止访问
404 - 未找到
500 - 服务器错误
```

### HTTP操作常见问题

#### 问题1: 连接超时
**原因**: 网络问题或服务器响应慢
**解决**:
1. 检查网络连接
2. 增加超时时间
3. 检查URL是否正确

#### 问题2: SSL证书错误
**原因**: 证书过期或不受信任
**解决**:
1. 检查系统时间是否正确
2. 更新根证书
3. 联系网站管理员

#### 问题3: 跨域请求失败
**原因**: 浏览器安全策略限制
**解决**:
1. 使用服务器端代理
2. 联系API提供方启用CORS
3. 使用JSONP（如果支持）

## 🗄️ 数据库操作

### 功能概述
数据库模块支持SQLite数据库的创建、连接、数据插入、查询、更新和删除操作。程序会根据系统环境自动选择真实数据库模式或模拟模式。

### 创建数据库

#### 操作步骤
1. **点击"数据库操作"按钮** → 选择"创建数据库"选项
2. **设置数据库参数**:
   - **数据库文件路径**: 选择保存位置和文件名
   - **表名**: 输入要创建的表名
   - **列定义**: 输入列名和数据类型

3. **列定义格式**:
   ```sql
   id INTEGER PRIMARY KEY AUTOINCREMENT,
   name TEXT NOT NULL,
   age INTEGER,
   email TEXT UNIQUE,
   created_at DATETIME DEFAULT CURRENT_TIMESTAMP
   ```

4. **创建数据库**:
   - 点击"创建"按钮
   - 状态栏显示创建进度
   - 成功后显示确认消息

#### 创建示例
创建一个用户信息表：
```sql
-- 表名: users
-- 列定义:
id INTEGER PRIMARY KEY AUTOINCREMENT,
username TEXT NOT NULL UNIQUE,
password TEXT NOT NULL,
email TEXT,
age INTEGER,
city TEXT,
registration_date DATETIME DEFAULT CURRENT_TIMESTAMP
```

### 连接数据库

#### 操作步骤
1. **点击"数据库操作"按钮** → 选择"连接数据库"选项
2. **选择数据库文件**:
   - 点击"浏览"按钮
   - 选择已有的`.db`文件
   - 点击"打开"

3. **连接测试**:
   - 点击"连接"按钮
   - 程序测试连接并显示表信息
   - 成功后可以执行数据操作

### 数据操作

#### 插入数据
1. **选择已连接的数据库**
2. **点击"插入数据"选项**
3. **输入数据**:
   - 选择目标表
   - 在表格中输入要插入的数据
   - 每行代表一条记录

4. **执行插入**:
   - 点击"插入"按钮
   - 查看插入结果和影响的行数

#### 查询数据
1. **点击"查询数据"选项**
2. **设置查询条件**:
   - 选择要查询的表
   - 输入WHERE条件（可选）
   - 例如: `age > 25 AND city = '北京'`

3. **执行查询**:
   - 点击"查询"按钮
   - 结果显示在表格中
   - 显示查询耗时和结果数量

#### 更新数据
1. **点击"更新数据"选项**
2. **设置更新条件**:
   - 选择目标表
   - 输入WHERE条件确定要更新的记录
   - 设置要更新的字段和新值

3. **执行更新**:
   - 点击"更新"按钮
   - 确认更新影响的行数

#### 删除数据
1. **点击"删除数据"选项**
2. **设置删除条件**:
   - 选择目标表
   - 输入WHERE条件确定要删除的记录
   - 例如: `id = 10`

3. **执行删除**:
   - 点击"删除"按钮
   - 确认删除操作（重要数据会要求二次确认）

### 数据库操作示例

#### 完整操作流程示例
1. **创建数据库**:
   ```sql
   -- 数据库: company.db
   -- 表: employees
   CREATE TABLE employees (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       name TEXT NOT NULL,
       department TEXT,
       salary REAL,
       hire_date DATE
   );
   ```

2. **插入数据**:
   ```
   表: employees
   数据:
   name: 张三, department: 技术部, salary: 8000, hire_date: 2023-01-15
   name: 李四, department: 销售部, salary: 6000, hire_date: 2022-08-20
   ```

3. **查询数据**:
   ```
   条件: department = '技术部'
   结果: 显示技术部所有员工
   ```

4. **更新数据**:
   ```
   条件: name = '张三'
   更新: salary = 8500
   ```

5. **删除数据**:
   ```
   条件: id = 2
   结果: 删除李四的记录
   ```

### 数据库操作常见问题

#### 问题1: 无法创建数据库
**原因**: 权限不足或路径错误
**解决**:
1. 检查保存路径权限
2. 确保路径存在
3. 以管理员身份运行程序

#### 问题2: SQL语法错误
**原因**: 列定义或查询语句格式错误
**解决**:
1. 检查SQL关键字拼写
2. 确保逗号位置正确
3. 验证数据类型匹配

#### 问题3: 模拟模式提示
**原因**: 系统缺少SQLite驱动
**解决**:
1. 程序会自动切换到模拟模式
2. 模拟模式提供相同的功能
3. 数据在内存中操作，程序关闭后数据不保存

4. **网络连接**: 检查网络是否正常
5. **重启程序**: 尝试关闭并重新启动程序

### 常见错误及解决

#### 文件相关错误
| 错误信息 | 可能原因 | 解决方法 |
|---------|---------|----------|
| 文件不存在 | 路径错误或文件被删除 | 检查文件路径和名称 |
| 权限不足 | 没有读写权限 | 以管理员身份运行或修改权限 |
| 格式不支持 | 文件格式不兼容 | 转换文件格式或使用支持的格式 |
| 文件被占用 | 其他程序正在使用 | 关闭其他程序后重试 |

#### 网络相关错误
| 错误信息 | 可能原因 | 解决方法 |
|---------|---------|----------|
| 连接超时 | 网络慢或服务器无响应 | 检查网络连接，稍后重试 |
| DNS解析失败 | URL错误或DNS问题 | 检查URL格式，刷新DNS |
| SSL错误 | 证书问题 | 检查系统时间，更新证书 |
| 404错误 | 页面不存在 | 检查URL是否正确 |

#### 数据库相关错误
| 错误信息 | 可能原因 | 解决方法 |
|---------|---------|----------|
| 连接失败 | 数据库文件损坏 | 检查文件完整性 |
| SQL错误 | 语法错误 | 检查SQL语句格式 |
| 约束违反 | 数据不符合约束条件 | 检查数据类型和唯一性 |
