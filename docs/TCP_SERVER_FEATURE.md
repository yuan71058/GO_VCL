# TCP服务器功能使用指南

## 概述

TCP服务器功能允许应用程序在本地启动一个TCP服务器，监听指定端口，接受客户端连接，并进行双向通信。该功能通过界面按钮控制，可以随时启动和停止服务器。

## 功能特点

- **TCP服务器管理**：启动/停止TCP服务器
- **客户端连接管理**：自动管理客户端连接，支持多个客户端同时连接
- **消息收发**：支持与客户端的双向通信
- **实时日志**：在界面中显示服务器状态和客户端活动
- **连接统计**：记录服务器接受的连接数量
- **UTF-8编码支持**：所有消息采用UTF-8编码处理，解决了服务器重启后出现乱码的问题

## 使用方法

1. **启动TCP服务器**：
   - 在主界面点击"🔌 TCP服务"按钮
   - 服务器将在默认地址(localhost:8082)启动
   - 按钮文本将变为"⏹️ 停止服务"
   - 状态栏显示"TCP服务器运行中"

2. **停止TCP服务器**：
   - 当服务器运行时，再次点击"⏹️ 停止服务"按钮
   - 服务器将停止监听并断开所有客户端连接
   - 按钮文本将恢复为"🔌 TCP服务"
   - 状态栏显示"TCP服务器已停止"

3. **查看服务器状态**：
   - 在主界面的功能表格中查看TCP服务器状态
   - 在日志区域查看服务器活动和客户端连接信息

## 测试客户端

项目包含一个简单的测试客户端(`test_tcp_client.go`)，可用于测试TCP服务器功能：

```bash
go run test_tcp_client.go
```

该客户端将：
1. 连接到localhost:8082
2. 读取服务器欢迎消息
3. 发送测试消息
4. 读取服务器响应
5. 断开连接

## 默认配置

- **主机地址**：localhost
- **端口**：8082
- **最大客户端数**：无限制
- **消息缓冲区大小**：1024字节

## 注意事项

1. 确保所选端口未被其他应用程序占用
2. 服务器启动后，任何客户端都可以连接到指定地址
3. 服务器停止时，所有连接的客户端将被断开
4. 客户端连接是异步处理的，不会阻塞UI线程
5. 所有消息采用UTF-8编码，确保中文字符正确传输和显示
6. 服务器重启后不会出现乱码问题

## 技术实现

TCP服务器功能通过以下组件实现：

- **TCPServerManager**：管理服务器的生命周期和客户端连接
- **TCPClient**：表示单个客户端连接
- **UI集成**：通过UIInterface与主界面交互
- **并发处理**：使用goroutine处理多个客户端连接
- **UTF-8编码处理**：使用bufio.NewReader和strings.TrimSpace确保消息正确编码
- **消息格式标准化**：确保所有消息以换行符结尾，提高兼容性

## 故障排除

1. **端口占用**：如果启动失败，可能是端口被占用，可以修改代码中的默认端口
2. **连接失败**：确保服务器已启动且地址正确
3. **消息丢失**：检查网络连接和客户端代码

## API参考

### TCPServerManager方法

- `StartServer() error`：启动TCP服务器
- `StopServer() error`：停止TCP服务器
- `IsRunning() bool`：检查服务器是否运行中
- `GetServerInfo() map[string]interface{}`：获取服务器信息
- `GetConnectedClients() []map[string]interface{}`：获取已连接的客户端列表
- `BroadcastMessage(message string) error`：向所有客户端广播消息
- `SendMessageToClient(clientID, message string) error`：向指定客户端发送消息

### 事件回调

- `OnClientConnected(clientID string)`：客户端连接事件
- `OnClientDisconnected(clientID string)`：客户端断开连接事件
- `OnMessageReceived(clientID, message string)`：收到客户端消息事件
